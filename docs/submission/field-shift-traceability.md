## Reproducing the package

Package `field-shift-v2-0d12285bf7a9` is produced by the code of science commit `22f67ad` or any later commit that does
not change the four files listed in `manifest.identity.code` (their sha256 are part of the package id). The manifest
field `base_git_revision` reads `56b1af3`: that was the HEAD of a working tree with uncommitted changes when the
package was generated, and checking out `56b1af3` produces a different id (`d47aa512c3fb`, never published). The
producer does not yet record or refuse a dirty working tree; that is a known gap. `data/processed/` is not versioned in
the science repository: the package of record is the copy pinned in the app under
`apps/web/src/teammate/data/field-shift-v2/`, byte for byte.

- Temperature sensitivity (+1.5 °C): not calculated; it needs ET0 recomputed with a declared humidity policy.
- A strategy with a legume cover (crotalaria): not calculated; no validated parameters.
- Margin by strategy: not calculated; the scenario has no yield.
- Reading guide on the Municipality screen, Explore search fixes for US counties and a human review of the English
  texts of the older screens.
- United States in production: the batch is published in Supabase and works locally; the hosted API still returns only
  the four Brazilian places because the US source is not enabled in the service configuration.
- Tests that need database accounts, the live Python service, a screen reader or real devices.
